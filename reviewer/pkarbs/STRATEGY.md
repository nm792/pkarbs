Standing rule (Nick 26 Nov 05:09Z: "are you ensuring that the codification of each strategy is updated each day in the gits?"): this file is brought up to date **every day** and every change is dated in the changelog at the bottom. Any rule, parameter, code SHA or status change lands here the same day.
- Insights and the evidence behind them: `INSIGHTS.md`.
- Operational status and blockers: `PK-STRATEGY-STATUS.md`.
- This file is the single place that says exactly what each strategy IS.

All strategies are paper only. Nothing is traded or staged (SETTLED A6). Fills and P&L for any paper node come from Nautilus (G68), and every paper run happens on Prime (R-039).

Common facts, cited once and applying to every row:
- A1: each token is priced only from its own book.
- A3: a 250 ms taker hold applies on non-weather markets, unless the market's own `seconds_delay` says otherwise.
- Each market's own `feeSchedule` is read from gamma, with fee per share = rate x p x (1-p).
- Monte Carlo types are named in every result, per G64: type 1 is a random strategy on the same data; type 2 is randomised data.

Code SHAs are short commit ids on pkarbs `reviewer` unless another branch is named. "sha256" is the file hash IT pins.
